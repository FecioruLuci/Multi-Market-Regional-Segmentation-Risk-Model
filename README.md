🛠️ Data Pipeline & Technical Implementation
Data Processing & Modeling:

Handled and optimized large-scale datasets using Power Query and Excel data structures.

Built a robust relational setup ensuring proper integration between transaction metrics, product hierarchies, and regional data.

Dynamic KPI Logic:

Configured interactive Time Slicers (Timeline spanning 2010–2011) linked across all pivot caches to filter real-time metrics.

Implemented dynamic Best and Worst Product KPI cards based on revenue generation within the selected timeframe, shielded via error-handling logic (IFERROR / GETPIVOTDATA).

Advanced Formatting:

Applied custom dynamic number formatting ([<999950]0.0,"K";0.0,,"M") to data labels and charts for seamless scaling from thousands to millions.

🔍 Analytical Scope
ABC Market Classification: Segmented inventory and products to track performance tiers and concentration of revenue.

Geographical & Time-Series Analysis: Evaluated revenue distribution across international markets alongside historical performance trends between 2010 and 2011.

Product Volume & Distribution: Analyzed product counts per category and volume distribution across classification tiers.

📌 Summary
This project delivers a comprehensive, interactive view of international sales dynamics and inventory performance, designed for rapid executive decision-making. By pairing large-scale data processing with clean, dynamic dashboard components, it showcases core technical competencies in data modeling, dashboard design, and business intelligence.
