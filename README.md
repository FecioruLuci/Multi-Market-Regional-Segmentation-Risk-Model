# International Sales & ABC Classification Project

This project features an interactive **Excel Dashboard** backed by a robust data pipeline, analyzing an extensive international sales dataset (14M+ rows, 2010–2011). It focuses on inventory segmentation, revenue distribution across global markets, and dynamic product performance tracking.

## 🛠️ Data Pipeline & Technical Implementation

* **Data Processing & Modeling:** Handled and optimized large-scale datasets using **Power Query** and Excel data structures, ensuring proper integration between transaction metrics, product hierarchies, and regional data.
* **Dynamic KPI Logic:** Configured interactive **Time Slicers** (Timeline spanning 2010–2011) linked across all pivot tables to filter real-time metrics.
* **Best & Worst Performance Cards:** Implemented dynamic **Best and Worst Product KPI cards** based on revenue generation within the selected timeframe, utilizing robust error-handling (`IFERROR` combined with `GETPIVOTDATA`).
* **Advanced Formatting:** Applied custom dynamic number formatting (`[<999950]0.0,"K";0.0,,"M"`) to data labels and charts for seamless scaling from thousands to millions.

---

## 🔍 Analytical Scope

* **ABC Classification & Inventory:** Segmented products into performance tiers to track concentration of revenue and product distribution by category.
* **Geographical Revenue:** Evaluated revenue distribution across international markets and countries based on ABC classifications.
* **Time-Series Performance:** Tracked total revenue over time across the 2010–2011 historical timeline.
* **Volume Metrics:** Monitored total quantity sold alongside product counts per category.
